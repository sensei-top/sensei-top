Install

Windows

  1. Download the installer, a file ending in .exe.
  2. Run it. If Windows says Windows protected your PC, click More info, then Run anyway. The installer is not code-signed yet, so Microsoft Defender SmartScreen stops it the first time.
  3. Choose the language, English or Português (Brasil). The app opens in the same one.
  4. On the last page, choose whether Sensei Top starts when Windows starts. Leave it on if you can: the app records only the games it is running for.

It installs for your Windows user only and never asks for administrator rights. Closing the window keeps the app running in the system tray, still recording; to quit, use the tray icon's menu.

Linux and the Steam Deck

  1. Download the AppImage, a file ending in .AppImage, and move it to a folder of your own, such as Applications in your home folder. It updates itself by replacing this file, so keep it somewhere you can write to.
  2. Open the file's properties, allow it to run as a program, then double-click it. On the Steam Deck, do this in desktop mode.

On Linux, closing the window quits the app, and games you play afterwards are not recorded. To keep it running, turn on Keep running when the window is closed in Settings, under App. If the app does not start, the install guide has the fix for each system.

The first run

The first time it opens, the app walks you through setup, one short step at a time:

  1. Welcome to Sensei Top: choose the Language, English or Portuguese. What leaves this computer opens the list of everything the app downloads. If you used Sensei Top before, Restore a backup brings your match history back.
  2. Which do you play?: Arena, Magic Online or Both. The next steps set up only what you pick.
  3. Arena: the app looks for Arena's log and checks that Detailed Logs are on. If they are not, the step shows where to turn them on: in Arena, open Options, then Account, tick Detailed Logs (Plugin Support), close Arena and start it again, then press Check again. Without Detailed Logs, no Arena match is recorded.
  4. Magic Online: see below.
  5. Ready: play a match. It appears on Home when it ends. Where the app can update itself, this step has Check for a new version once a day; on Linux, it also offers Start Sensei Top when you log in.

Card data, about 80 MB, downloads on its own the first time the app opens, and Ready shows how far it has got. The deck guides need it. If the download fails, press Try again there, or Download card data in Settings, under Sources.

If you play Arena, Home shows Turn on Detailed Logs in Arena until Arena's log says they are on, with the same steps and Check again. Arena writes that line only when it starts, so start Arena again before you check.

To go through the steps again, open Settings, then App, and press Go through them again.

Keep the app running while you play. Arena empties its log every time it starts, and keeps the session before only until it starts again. A session played with Sensei Top closed is gone after two Arena launches. Start when Windows starts, or Start when you log in on Linux, under App in Settings, takes care of it.

Magic Online

Magic Online's log never says which player is you, or which deck you played, so the app needs two things from you, in its welcome step or later in Settings, under Sources:

  • Your name on Magic Online, so it can tell your games from your opponents'.
  • The Folder of game logs, where Magic Online writes files named Match_GameLog. On Windows, when the app finds the folder Magic Online is writing, it fills it in for you to save. Otherwise it is under AppData\Local\Apps\2.0\Data; under Wine or Proton, inside that prefix's drive_c folder.
  • Optionally, the Folder of decks, where you export decks from Magic Online as .dek files. The app already reads the decks Magic Online keeps beside its game logs; this folder adds the ones you export.

Each game is read once it ends. Magic Online moves this folder when it updates, so if new games stop appearing, choose the folder again in Settings, under Sources.

A Magic Online match counts toward one of your decks once you pick the deck. Open the match and answer Which deck was this?; with many matches waiting, use the Needs a deck card on Home instead. It groups the matches by the deck saved in Magic Online that holds the most cards you played, and one confirmation picks that deck for a whole group. Magic Online matches never appear on Live, which follows Arena only.

Something looks wrong

No Arena matches at all

Check that Detailed Logs (Plugin Support) is ticked in Arena, and that Arena was restarted after you ticked it. Then open Settings, under Sources: it says whether the app found Arena's log. If you run Arena through Lutris, Bottles or a Wine prefix of your own, set the Log file there; the install guide says where it is.

Matches from an earlier session are missing

Arena empties its log every time it starts. A session played with Sensei Top closed is still in the log until Arena's next launch, and gone after that. Keep the app running whenever you play.

The app says Watcher stopped or Tracker not running

Quit Sensei Top and open it again. On Windows, quit from the tray icon's menu: closing the window leaves it running. If it happens again, send a problem report: the reason is in the app's log.

The app does not start

Its window says where its log file is. Send that file with a few lines about what happened, as below.

Dates or times look wrong

In Settings, under Sources, set the Date order to Day first or Month first instead of Read it from the log.

A Magic Online match is missing

Check Your name there and the Folder of game logs in Settings, under Sources. After a Magic Online update the folder has usually moved. A game appears only once it has ended.

The opponent's deck is wrong or unnamed

The app names the opponent's deck from the cards they revealed, so a game where they showed few cards can be named wrong or not at all. On the match's page, press Correct the deck and pick the right one. The app keeps your pick.

Send a problem report

When something is wrong, a diagnostics export shows what the app saw. It takes a minute.

  1. Open Settings, then App, and press Export diagnostics. The tray icon's menu has the same entry.
  2. A window lists what goes in. Leave Include Player.log unticked unless you are asked for it: Arena's log names your opponents and your decks.
  3. Press Save as… and choose where to save the zip.
  4. Send the zip with a few lines: what you did, what you expected, what the app showed, and what the game showed.

What is in the zip

  • The app's own log files.
  • The app's settings, with every key and your Magic Online name removed.
  • What the app can find on your computer: Arena's log, Magic Online's folder, the card data and the database.
  • How many rows each table of the database holds. The counts only, never the rows.

Never in it: your database, so none of your matches, and no key. Arena's Player.log goes in only when you tick the box.

A problem that comes and goes

Turn on Diagnostic mode in Settings, under App. The app then writes much more detail to its log; turning it on or off restarts the tracker for a moment. Use the app until the problem shows up again, export, then turn it off.

Where to send it

Open an issue with the bug form and attach the zip. Issues are public, so never attach Player.log to one. If something stopped appearing after Arena or Magic Online updated, the log change form is the better one. To send a report privately, e-mail it to contact@senseitop.com. A question rather than a problem goes to Discussions.
