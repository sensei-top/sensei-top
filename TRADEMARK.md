# The Sensei Top name and logo

The code in this repository is free software under the AGPL-3.0-only
([LICENSE](LICENSE)). The name "Sensei Top", and any logo this project
publishes for it, are not part of that licence. The project's maintainer
uses them as unregistered trademarks (Sensei Top™), and they exist to tell
people which software this project published.

This page says what you may do without asking.

## You may

- Say in words that your work is **built on Sensei Top**, **based on Sensei Top**
  or **compatible with Sensei Top**.
- Use the name to refer to this project: in an article, a video, a review,
  a comparison, a bug report.
- Distribute unmodified copies of an official release under its own name.

## You may not

- Distribute a modified version under the name "Sensei Top", or under a name
  close enough to be confused with it. **A fork picks its own name and
  logo.**
- Use the name or logo in a way that suggests this project endorses, runs
  or answers for your version, your service or your product.
- Use the logo as the icon of your own application, or register the name
  or one like it as a domain, an account or a trademark.

## Why

The AGPL gives everyone the right to change this software and to share the
result. It does not make every changed copy ours. Someone who installs a
program called Sensei Top should get what this project published, with the
privacy promises this project made.

For anything this page does not cover, write to **contact@senseitop.com**.
