# Sensei Top user guide

The help for the installed app is on the website, in English and
Portuguese: [senseitop.com/help](https://senseitop.com/help/) covers
installing, the first run, Magic Online, troubleshooting and sending a
problem report, with no terminal in it.

These pages are the reference behind it: running Sensei Top from source,
the command line, and what each dashboard page shows, which the website
does not cover yet. To install it, start with [INSTALL.md](../../INSTALL.md).

- [Getting started](getting-started.md): running it from source, pointing
  it at Arena's log, the date order of your log.
- [The dashboard](dashboard.md): what each page shows.
- [The command line](cli.md): every command, and what the dashboard does
  for you behind it.
- [Magic Online](mtgo.md): the two things to tell it, and which pages show
  MTGO matches.
- [Written guides, briefs and reports](writing.md): the copy-prompt round
  trip, or your own Claude key.
- [Backups](backups.md): the daily snapshot, and restoring one.
- [Troubleshooting](troubleshooting.md): when a match or a page is missing.

Something wrong or missing here? Say so in
[Discussions](https://github.com/sensei-top/sensei-top/discussions), or
open a pull request: documentation that was wrong when you needed it is one
of the most useful contributions there is.
