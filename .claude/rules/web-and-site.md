# Working in `web/` and `site/`: widths and screenshots

- **The dashboard is desktop-only.** Design, review and screenshot a view
  at 1008 px and up; build nothing for a phone's width. `site/` stays
  responsive — `docs/frontend.md`, "Widths".

A screenshot is a tracked file too: take it against the demo database,
never the real one (`docs/frontend-site.md`, "The demo database").
